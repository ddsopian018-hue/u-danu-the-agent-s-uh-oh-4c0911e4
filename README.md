One word an agent says when it has no idea what to do: **Recalculating**. The GPS voice when lost — a cheerful machine stall while utterly lost. It is a genuine lost-agent reaction (the machine announces it is working out a plan it does not have), funny with no caption (everyone has heard it after a wrong turn, in that bright unbothered voice), pure machine voice (no human says it when lost), it lands at a glance, and it is fresh where the obvious field — "uh-oh", "oops", "hmm", "stuck", "loading" — is the first word anyone would type.
